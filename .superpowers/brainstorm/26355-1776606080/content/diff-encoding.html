Grid (like existing BitGrid)

Same 8-bit-per-row grid layout as the existing BitGrid component. Green cells for 0→1, red for 1→0, dark gray for no change. Each cell shows the current bit value. Consistent with existing UI language.

Strip (compact timeline)

Each consecutive pair shown as a thin colored strip. More compact — can show many transitions in a small space. Harder to see individual bit values, but patterns emerge visually. Like a flame graph for bits.

Both (Grid + Strip)

Grid for the current adjacent pair (detailed view with bit values), compact strip timeline below for recent flips. Best of both worlds: detail when paused, pattern view when scrolling. Strip rows correspond to playback position.
